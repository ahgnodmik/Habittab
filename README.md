# HabitTab

습관 관리 앱 - 매일의 습관을 체크하고 달성률을 확인할 수 있는 Flutter 앱입니다.

## 주요 기능

### 📝 습관 관리
- **습관 추가**: 새로운 습관을 추가하고 10가지 미리 정의된 색상 중에서 선택
- **습관 편집**: 기존 습관의 이름과 색상을 수정
- **습관 삭제**: 더 이상 필요하지 않은 습관을 제거

### 🎨 색상 선택
습관 추가/편집 시 다음 10가지 색상 중에서 선택할 수 있습니다:
- 🔵 파란색 (기본)
- 🟢 초록색
- 🟡 노란색
- 🔴 빨간색
- 🟣 보라색
- 🟠 주황색
- 🩷 핑크색
- 🟤 갈색
- ⚫ 검은색
- ⚪ 회색

### 📅 달력 뷰
- **월간 달력**: 한 달 단위로 습관 달성 현황을 확인
- **일간 뷰**: 특정 날짜의 습관 체크리스트 확인
- **달성률 표시**: 각 습관별 달성률을 시각적으로 표시

### 📊 통계
- **월간 통계**: 월별 습관 달성률 확인
- **습관별 통계**: 개별 습관의 성과 분석

### 🏠 홈 위젯
- **1x4 위젯**: 홈 화면에 최대 4개 습관을 한 줄로 표시
- **원터치 체크**: 위젯에서 직접 습관 체크/해제 가능
- **자동 업데이트**: 앱에서 습관을 수정하면 위젯도 자동 업데이트

## 사용법

1. **앱 실행**: 앱을 실행하면 메인 화면에서 습관 목록을 확인할 수 있습니다.

2. **습관 추가**:
   - 하단의 "습관 추가" 버튼을 탭합니다
   - 습관 이름을 입력합니다
   - 10가지 색상 중 원하는 색상을 선택합니다
   - "추가" 버튼을 탭하여 습관을 저장합니다

3. **습관 체크**:
   - 각 습관 옆의 체크박스를 탭하여 완료 표시
   - 체크된 습관은 시각적으로 구분됩니다

4. **습관 편집**:
   - 메뉴에서 "습관 편집"을 선택합니다
   - 편집하고 싶은 습관을 선택합니다
   - 이름과 색상을 수정한 후 "저장"을 탭합니다

5. **달력 보기**:
   - 메뉴에서 "달력 보기"를 선택합니다
   - 월간 달력에서 습관 달성 현황을 확인할 수 있습니다

6. **홈 위젯 추가**:
   - 메뉴에서 "홈 위젯 추가"를 선택합니다
   - 위젯 설정 화면에서 "위젯 업데이트"를 탭합니다
   - 홈 화면을 길게 누르고 "위젯"을 선택합니다
   - "Habittab" 위젯을 찾아 홈 화면으로 드래그합니다

## 기술 스택

- **Flutter**: 크로스 플랫폼 모바일 앱 개발
- **SharedPreferences**: 로컬 데이터 저장
- **Table Calendar**: 달력 UI 컴포넌트
- **Home Widget**: 홈 화면 위젯 지원

## 설치 및 실행

```bash
# 의존성 설치
flutter pub get

# 앱 실행
flutter run
```
