개인정보 처리방침

본 개인정보 처리방침은 습관 관리 앱인 Habittab(개발자: 김동하)에 적용됩니다.

1. 수집하는 개인정보 항목

Habittab 앱은 사용자의 개인정보를 직접 수집하지 않습니다. 앱 내에서 생성되는 습관 데이터는 기기 내부에만 저장되며, 외부 서버로 전송되지 않습니다.

2. 개인정보의 수집 방법

해당 앱은 별도의 회원가입, 로그인 기능이 없으며, 사용자가 입력한 습관 정보는 기기 내부 저장소에만 보관됩니다. 자동으로 개인정보를 수집하지 않습니다.

3. 개인정보의 이용 목적

개인정보를 수집하지 않으므로 별도의 이용 목적이 존재하지 않습니다. 습관 데이터는 오직 사용자의 습관 관리 목적으로만 사용됩니다.

4. 개인정보의 보관 및 파기

개인정보를 서버에 보관하지 않으며, 습관 데이터는 기기 내부에만 저장됩니다. 앱을 삭제하면 모든 데이터가 함께 삭제됩니다.

5. 제3자 제공 및 외부 서비스

당사는 사용자 정보를 제3자에게 제공하지 않습니다. 앱에는 Google AdMob 광고가 포함되어 있으나, 이는 익명의 광고 식별자만 사용하며 개인정보를 수집하지 않습니다.

6. 사용자의 권리

사용자는 언제든지 앱을 삭제하여 사용을 중단할 수 있으며, 앱 삭제 시 모든 습관 데이터가 함께 삭제됩니다. 별도의 데이터 삭제 요청은 필요하지 않습니다.

7. 개인정보 보호조치

앱은 개인정보를 외부로 전송하지 않으므로 보안 리스크가 최소화됩니다. 습관 데이터는 기기 내부에만 암호화되어 저장되며, Google Play의 개인정보 보호 가이드를 준수합니다.

Privacy Policy

This Privacy Policy applies to the habit tracking app Habittab, developed by Kim Dongha.

1. Personal Data Collected

The Habittab app does not collect any personal information from users. Habit data created within the app is stored only on the device and is not transmitted to external servers.

2. Method of Data Collection

The app does not include sign-up or login functionality. Habit information entered by users is stored only in the device's internal storage. No personal data is collected automatically.

3. Purpose of Data Use

There is no specific purpose of personal data use as no personal data is collected. Habit data is used solely for the user's habit management purposes.

4. Data Storage and Disposal

No personal data is stored on external servers. Habit data is stored only on the device's internal storage. When the app is deleted, all data is deleted together.

5. Third-Party Sharing and Services

The app does not share user information with any third party. The app includes Google AdMob advertisements, which use only anonymous advertising identifiers and do not collect personal information.

6. User Rights

Users may delete the app at any time to stop its use. When the app is deleted, all habit data is deleted together. There is no need to request separate data deletion.

7. Data Protection Measures

Since the app does not transmit personal data externally, security risks are minimized. Habit data is stored encrypted only on the device's internal storage and complies with Google Play's privacy protection guidelines.

8. Data Controller Contact Information

  • Controller: Kim Dongha
  • Email: samdongpm@gmail.com

9. Changes to This Policy

Any changes to this policy will be notified via this web page or through an app update.
